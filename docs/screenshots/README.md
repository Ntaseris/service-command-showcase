# Screenshot notes

These screenshots demonstrate the application’s actual components and styles, rendered locally with fictional data and neutral branding. Brand artwork and truck/team labels are anonymized for this case study; workflow layout and controls are retained.

All displayed leads, destinations, schedules, movement timestamps and inventory counts are examples. The report uses a generic client/site with empty fields and photo controls. No live service records, submitted photos, account information or communications were accessed for these captures.

Application requests were replaced by local fixtures. Phone views use a 430 CSS-pixel viewport; desktop views use 1440 CSS pixels. Images are captured at 2× resolution and contain no text or EXIF metadata.
